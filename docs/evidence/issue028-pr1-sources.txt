[O1] (D) https://developers.openai.com/api/docs/guides/rate-limits
     (redirecionado de platform.openai.com/docs/guides/rate-limits, HTTP 301)

       créditos, teto US$ 500/mês); Launch (US$ 100, teto US$ 5.000); Grow (US$ 500, teto US$ 200.000).

[O3] (D) https://developers.openai.com/api/docs/pricing
     - "Prices per 1M tokens."

ANTHROPIC
-------------------------------------------------------------------------------
[A1] (D) https://platform.claude.com/docs/en/api/rate-limits
     (redirecionado de docs.claude.com/en/api/rate-limits, HTTP 301)
     - Spend caps mensais: Start US$ 500; Build US$ 1.000; Scale US$ 200.000; Custom sem teto.
     - Tier Evaluation inicial "with limits below the standard limits".
     - Rate limits RPM/ITPM/OTPM por modelo; ramp limits; token bucket.
     - Erros: 429 rate_limit_error; error_code "enforced_spend_limit_reached" (sem retry-after) e
       "ramp_limit_exceeded".
     - "All limits described here represent maximum allowed usage, not guaranteed minimums."
     - A página não descreve camada gratuita de API.
     Conclusão: API paga; nenhuma camada gratuita comprovada.

[A2] (D) https://platform.claude.com/docs/en/about-claude/pricing
     - Preços em USD por MTok. Ex.: Claude Opus 5.5 US$ 4 / US$ 20; Claude Sonnet 5.5 US$ 2 / US$ 10;
       Claude Haiku 5.5 US$ 0,10 / US$ 0,50 (prompts até 100.000 tokens).
     - inference_geo "US-only" com multiplicador 1.1x.
     Conclusão: API por consumo; opção de inferência só nos EUA.

[A3] (D) https://code.claude.com/docs/en/iam
     (redirecionado de docs.claude.com/en/docs/claude-code/iam, HTTP 301)
     - Contas: "Claude Pro, Max, or Ultra subscription", Teams/Enterprise, Claude Console, provedores de nuvem.
     - ANTHROPIC_API_KEY "Sent as the X-Api-Key header".
     - "claude setup-token": token OAuth de um ano; "This token authenticates with your Claude subscription".
     Conclusão: Claude Code aceita assinatura ou chave de API.

[A4] (D) https://code.claude.com/docs/en/legal-and-compliance
     (redirecionado de docs.claude.com/en/docs/claude-code/legal-and-compliance, HTTP 301)
     - Commercial Terms para Team, Enterprise e API; Consumer Terms para Free, Pro, Max e Ultra.
     - Rodar Claude Code "in your products or services (e.g. in hosted sandboxes or other agent
       infrastructure) requires agreeing to our Commercial Terms"; binário não modificado; "Customers may
       not pay for, resell, or intermediate Claude usage on their end users' behalf."
     - "OAuth authentication is intended exclusively for purchasers of Claude Free, Pro, Max, Ultra, Team,
       and Enterprise subscription plans".
     - "Anthropic does not permit third-party developers to offer Claude.ai login into their own
       applications, or to route requests through Free, Pro, Max, or Ultra plan credentials on behalf of
       their users."
     - "developers may not collect, store, or intermediate Claude.ai credentials or session tokens"
     - "Advertised usage limits for Pro, Max, and Ultra plans assume ordinary, individual usage".
     Conclusão: o ACC não usa nem guarda credencial de assinatura; Claude Code hospedado exige Commercial
     Terms; caso do PO usando a própria credencial fica para decisão da #008/#031 (P4).

[A5] (B) https://platform.claude.com/docs/en/manage-claude/api-and-data-retention
         https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data
     - API: entradas e saídas apagadas "within 30 days of receipt or generation" (salvo exceções).
     - Conteúdo sinalizado: até 2 anos; pontuações de classificação: até 7 anos.
     - ZDR por acordo; "Covered Models" com retenção de 30 dias "on every platform", vigente desde 2026-06-09.
     Conclusão: retenção comercial padrão de 30 dias.

[A6] (B) https://www.anthropic.com/news/updates-to-our-consumer-terms
         https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data
     - Consumidor (Free/Pro/Max): opt-in de treinamento com retenção de 5 anos; sem opt-in, 30 dias.
     - Não se aplica a serviços sob os Commercial Terms (Team, Enterprise, API).
     Conclusão: no modo assistido, o PO deve manter o treinamento desligado (D4).

[G1] (D) https://aistudio.google.com/docs/terms
     (redirecionado de ai.google.dev/gemini-api/terms, HTTP 301). "Effective March 23, 2026".
     - Serviços não pagos: "Google uses the content you submit to the Services and any generated responses
       to provide, improve, and develop"; revisores humanos podem ler.
     - Serviços pagos: "Google doesn't use your prompts" ... "or responses to improve our products";
       registro por tempo limitado para abuso.
     - "Do not submit sensitive, confidential, or personal information to the Unpaid Services."
     - EEE, Suíça e Reino Unido: só serviços pagos. Idade mínima: 18 anos.
     Conclusão: tier gratuito proibido para dados de projetos (D4).

[G2] (D) https://aistudio.google.com/docs/rate-limits
     (redirecionado de ai.google.dev/gemini-api/docs/rate-limits, HTTP 301)
     - RPM, TPM, RPD (reinicia à meia-noite do Pacífico); "Rate limits are applied per project, not per API key."
     - Tiers: Free; Tier 1 (faturamento ativo); Tier 2 (US$ 100 + 3 dias); Tier 3 (US$ 1.000 + 30 dias).
     - "Specified rate limits are not guaranteed and actual capacity may vary."

[G3] (D) https://aistudio.google.com/docs/api-key
     (redirecionado de ai.google.dev/gemini-api/docs/api-key, HTTP 301)
     - Cabeçalho x-goog-api-key; "Every Gemini API key is associated with a Google Cloud project."
     - Chaves de autorização ligadas a conta de serviço; padrão no AI Studio desde 2026-05-28.
     - "Never check API keys into source control systems like Git."; proxy no backend; Secret Manager.

[G4] (D) https://aistudio.google.com/docs/pricing
     - Free: "Content used to improve our products." Pago: "Content not used to improve our products."
     - Ex.: Gemini 3.5 Flash-Lite US$ 0,30 / US$ 2,50 por 1M tokens; Gemini 3.1 Pro Preview US$ 2,00 / US$ 12,00
       (≤200k tokens).

[G5] (D) https://aistudio.google.com/docs/google-ai-plans
     (redirecionado de ai.google.dev/gemini-api/docs/google-ai-plans, HTTP 301)
     - "Google AI plan benefits for developer usage apply only within the Google AI Studio web interface."
     - "Google bills and manages Gemini API usage (such as using API keys or external applications) separately."
     Conclusão: assinatura não inclui API.

[G6] (B) https://support.google.com/gemini/answer/13594961 (Gemini Apps Privacy Hub)
     - Revisores humanos podem ler conversas mesmo com a atividade desligada.
     - Atividade desligada: retenção de 72 h; conversas revisadas: até 3 anos; padrão 18 meses com atividade ligada.
     Conclusão: modo assistido com dados privados só com autorização (D4).
